# Independent base-R pairwise numerical oracle (experimental)

This directory addresses the **absence of a genuinely executed R reference in CI** and the **low-precision Student-t critical-value lookup** it exposed. The pre-existing `tests/r_parity_harness.cjs` is ported dashboard JavaScript, **not R**. Its baseline and published numerical anchors are valuable but must not be relabelled as live R parity.

The new isolated CI job runs **R 4.4.3** (base `stats`, no CRAN packages), Python 3.11.9 and Node 20.19.5 on Ubuntu 24.04. GitHub Actions themselves are pinned to immutable action commits in `.github/workflows/ci.yml`. The job fails if R is missing or the version is not exactly 4.4.3. It does not silently skip the test. Run locally with these three runtimes installed:

```sh
python -m unittest discover -s oracle-tests -p 'test_*.py' -v
```

**What it actually compares:** the shipped `assets/vendor/pairwise-pool.js` output versus a separately implemented base-R calculation of inverse-variance log-RR/log-OR, Q, I², PM/DL between-study variance, random-effects mean, floored Hartung–Knapp–Sidik–Jonkman 95% CI and a Cochrane `t(k-1)` prediction interval. Two clearly synthetic, independent-comparison input sets are crossed with RR/OR and PM/DL (eight live R executions). There are also failure-injection assertions for rejected unsupported methods, intentionally unmatched zero-cell corrections, corrupted R output and numerical tampering.

**Method/tolerance contract:** raw binomial tables with strictly positive counts in every cell, at least three studies, 95% intervals, inverse-variance random effects. For the raw log-scale estimators, tolerance is 1e-8 absolute/relative. On the exponentiated CI/PI endpoints, the tolerance is 1e-6 absolute or relative. The JS engine now uses high-precision t-quantile constants for df 1–30; the originally shipped three-decimal lookup caused a genuine **0.05–0.07% error in upper prediction-interval endpoints** for these synthetic tests. For integer df > 30, the engine now uses a fourth-order Cornish–Fisher t-quantile expansion instead of its truncated approximation. Six additional synthetic RR/OR × DL cases at k = 32, 45, and 104 execute **native R 4.4.3** and check every output, including CI/PI endpoints at 1e-7 absolute/relative tolerance. A deliberately corrupted upper PI must fail. This is numerical *approximation* verified at those three df values, not a mathematically exact quantile, not an all-df accuracy guarantee, and not direct metafor validation. Those tolerances are not a claim of bitwise equality. PM uses generalized-Q inversion in independently implemented base R; DL uses the moment formula. When `tau2=0`, the convention makes the PI match the floored HKSJ CI.

**Near-zero PM root regression:** a synthetic three-study, high-count stress test brackets the generalized-Q threshold (Q slightly below and above k−1). An absolute stopping width of 1e−12 previously returned τ²≈4.55e−13 rather than the positive root near 1.8e−15. The JS bisection now stops only when its bracket cannot be further divided in double precision; the independently written base-R `uniroot` reference uses `tol=1e-20` for this stress case. A separate explicit 2e−16 τ² tolerance avoids hiding the defect under the broader 1e−8 comparison tolerance. Such large counts are **synthetic numerical stress inputs**, not clinical evidence; this is **not** metafor parity or prospective clinical validation.

**Not yet tested by this suite:** real trial extraction; numerical accuracy of continuity corrections and unequal-arm rare events; REML; direct `metafor::rma.uni` or RevMan execution; multi-arm covariance; Meta-Harness end-to-end interoperability; external clinical validation; Windows/macOS. The fixed R version does not pin the operating-system image to a digest; the Ubuntu runner image may change. Report these as **NOT TESTED**. Do not compare these cases to `metafor` results obtained with `test="knha"` without first matching the floor convention.

Methods: [Cochrane Handbook Chapter 10, §10.10.4.3](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-10); [metafor discussion of PM and HKSJ](https://wviechtb.github.io/metafor/reference/misc-recs.html); [R `stats::qt` documentation](https://search.r-project.org/R/refmans/stats/help/qt.html). This is **independent base R**, not a `metafor` parity claim.
