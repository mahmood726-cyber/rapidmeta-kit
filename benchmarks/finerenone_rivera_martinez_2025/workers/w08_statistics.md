## Independent execution, source boundary and software

A Python 3.13 numerical oracle was **actually executed** using SciPy 1.17.0, NumPy 2.3.5, statsmodels 0.14.6. The independent analytic routines compute generic log-ratio inverse-variance normal CI, Cochran Q, nonnegative DL tau², restricted-likelihood REML tau², Paule–Mandel tau², and unmodified and floor-protected Hartung–Knapp–Sidik–Jonkman (HKSJ) t(2) intervals. Two independent REML solvers (analytic restricted-score root and direct restricted-likelihood bounded minimization) agreed. DL and PM compared to statsmodels `combine_effects`; when statsmodels returns **negative raw DL tau²**, the oracle correctly truncates at zero and cross-checks the fixed-effect estimate rather than using invalid negative between-study variance. Reverse-arm negative controls (pooled inverse ratios) passed for all 2×2 endpoints. Exact run outputs and validation flags: [w08_statistics_oracle_log_20261107.json](w08_statistics_oracle_log_20261107.json).

Definition and denominators pending source adjudication.

For binary rows, `y=ln((a/nT)/(c/nC)); v=1/a - 1/nT + 1/c - 1/nC` (no zero events). For HR/CIs, `y=ln(HR); v=((ln(U)-ln(L))/3.92)^2`. `w=1/(v+tau²)`, `mu=Σ(w*y)/Σw`, conventional 95% CI `exp(mu ± 1.96/sqrt(Σw))`; `Q=Σ((y-mu_FE)^2/v)`; `I²=max(0,(Q-2)/Q)*100`. REML score `Σw²(y-mu)²-Σw+(Σw²)/(Σw)=0` at tau²≥0, with independent restricted likelihood minimization. HKSJ: df=2, `q=Σw(y-mu)^2/2`, CI `exp(mu ± t_.975,2 * sqrt(q/Σw))`; safeguarded variant floors `q≥1`. **HKSJ is sensitivity, not post-hoc claimed paper method.**
